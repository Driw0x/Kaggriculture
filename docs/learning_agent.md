# Learning Agent

## 1. Objective

The learning agent is an experimental alternative to the deterministic heuristic agent.

The objective is to learn strategic decisions from high-performing Kaggriculture agents while keeping deterministic execution for low-level farm actions and pathing.

The planned architecture is hybrid:

```text
Game observation
       |
       v
Learning policy
       |
       v
Strategic decisions
       |
       v
Deterministic planner
       |
       v
Legal Kaggriculture actions
```

The learning policy is responsible for strategy. The deterministic planner remains responsible for executing these decisions safely and efficiently.

## 2. Approach

The learning pipeline is divided into two main stages:

1. Imitation Learning
2. Reinforcement Learning

Imitation Learning is used first to learn from strong existing agents. Reinforcement Learning can then fine-tune the learned policy through interaction with the Kaggriculture environment.

Pure Reinforcement Learning from scratch can later be evaluated as a baseline, but it is not the primary approach.

## 3. Expert Replays

Expert demonstrations are collected from high-ranking Kaggriculture leaderboard submissions.

The downloader follows the Kaggle simulation competition hierarchy:

```text
Leaderboard
    |
    v
Top N teams
    |
    v
Best submission
    |
    v
Episodes
    |
    v
Replay JSON
```

Replays are stored without preprocessing:

```text
data/
└── expert_replays/
    ├── top_01/
    │   ├── <episode_id>.json
    │   └── ...
    ├── top_02/
    │   └── ...
    └── ...
```

Example:

```bash
python scripts/download_replays.py --top 10 --episodes 40
```

This targets up to 400 expert replays. Existing files are skipped so interrupted downloads can be resumed.

## 4. Replay Dataset

`src/learning/replay_dataset.py` loads the raw replay files.

Each usable sample preserves:

```text
observation_t
      |
      v
action_t
```

The raw observation and action are kept intact during loading. This avoids losing information before the learning representation has been finalized.

Replay files are read recursively from the expert replay directory.

## 5. State Encoding

`src/learning/state_encoder.py` converts a raw Kaggriculture observation into a fixed numerical feature vector.

The current representation contains strategic information including:

- day and hour;
- money;
- hired workers;
- unlocked land;
- shed contents;
- available seeds;
- carried products;
- market inventory;
- market prices;
- unlocked shops;
- crop production state;
- animal production state;
- watering state;
- feeding state;
- care state;
- fertilizer state.

Tile positions are not currently encoded individually. Instead, production is aggregated by crop and animal type because low-level spatial execution is intended to remain the responsibility of the deterministic planner.

The first learning model also deliberately excludes opponent state. Opponent modeling is reserved for a later variant after the base learning agent has been optimized.

## 6. Decision Extraction

`src/learning/decision_extractor.py` converts raw expert actions into strategic learning targets.

The current strategic targets include:

```text
HIRE
BUY_LAND
BUY_SEED
BUY_ANIMAL
BUY_PRODUCT
SELL
PLANT
PLACE
FERTILIZE
BUILD_COOP
BUILD_PASTURE
```

Low-level execution actions are deliberately excluded from the learning target:

```text
NORTH
SOUTH
EAST
WEST
PASS
PICKUP
DROP
WATER
FEED
CARE
HARVEST
COLLECT_FERTILIZER
```

These actions can be generated by the deterministic planner from the strategic objectives selected by the learned policy.

## 7. Replay Analysis

Before training the Behavioral Cloning model, the expert replay dataset must be analyzed.

The analysis script examines:

- number of replays;
- number of usable samples;
- invalid samples;
- represented expert teams;
- frequency of each strategic decision;
- strategic decisions by day;
- strategic decisions by hour;
- proportion of observations without a strategic decision.

Run:

```bash
python scripts/analyze_replays.py
```

This analysis determines the final temporal representation used for training.

Two representations are currently considered.

### Tick-level

```text
observation at tick t
        |
        v
strategic decision at tick t
```

This representation directly follows the replay structure. However, most ticks may contain no new strategic decision, creating a strong class imbalance.

### Aggregated strategic decisions

A higher-level representation may instead aggregate decisions over a larger strategic interval, for example a game day.

```text
strategic state
      |
      v
daily strategic decisions
```

The final choice will be based on the distribution observed in the expert replay dataset.

## 8. Behavioral Cloning

The first trained agent will use Behavioral Cloning.

The planned pipeline is:

```text
Expert replay JSON
        |
        v
ReplayDataset
        |
        v
State encoder
        |
        v
Decision extractor
        |
        v
Behavioral Cloning model
        |
        v
Strategic policy
```

The model will learn to approximate the strategic decisions of high-ranking Kaggriculture agents.

The exact model architecture and output heads will be defined after the replay analysis has established the final learning targets.

## 9. Hybrid Agent

The learned model is not intended to directly replace all existing planning logic.

The target architecture is:

```text
Observation
     |
     v
State encoder
     |
     v
Learned strategic policy
     |
     +-------------------------+
     |                         |
     v                         v
Production targets       Market / workforce
     |                         |
     +------------+------------+
                  |
                  v
        Deterministic planner
                  |
                  v
     Worker allocation / pathing
                  |
                  v
         Kaggriculture action
```

This separation allows the learning model to focus on strategic decisions while deterministic logic enforces game mechanics and execution constraints.

## 10. Reinforcement Learning

After Behavioral Cloning, the learned policy can be fine-tuned using Reinforcement Learning.

The main objective remains the Kaggriculture reward:

```text
final money
```

Behavioral Cloning provides an initial policy close to strong expert behavior. Reinforcement Learning can then optimize beyond direct imitation.

The planned sequence is:

```text
Expert replays
      |
      v
Behavioral Cloning
      |
      v
Pretrained strategic policy
      |
      v
Reinforcement Learning
      |
      v
Optimized hybrid agent
```

## 11. Evaluation

Learning agents will be compared against the deterministic heuristic agent using repeated Kaggriculture simulations.

Planned comparisons include:

```text
Heuristic agent
Behavioral Cloning
Behavioral Cloning + Reinforcement Learning
Reinforcement Learning from scratch
```

Evaluation should use multiple games and report at least:

- minimum reward;
- maximum reward;
- mean reward;
- reward distribution;
- failure cases.

The deterministic heuristic agent remains the reference baseline.

## 12. Opponent Modeling

Opponent modeling is deliberately excluded from the initial learning agent.

The first objective is to maximize the performance of the base policy without depending on opponent information.

Once the optimized version is stable, two variants can be maintained:

```text
Base optimized agent
Base optimized agent + opponent modeling
```

This keeps the effect of opponent modeling measurable independently from the core strategy.
